# v0.5.0-rc11 → v0.5.0-rc12: P2-3 Source 模式 wikilink 高亮 + Insert Wikilink

> **核心**: Source (raw markdown) 模式也走 attributed string, `[[xxx]]` / `[[xxx|alias]]` 高亮蓝色下划线 + 可点击跳转. 菜单栏 Cmd-Shift-K 插入 wikilink.

## 1. 背景与动机

v0.4 渲染模式 (MarkdownRenderer) 已经支持 `[[wikilink]]` 蓝色下划线 (line 418-441), Source 模式 (raw markdown 编辑) 走 NSTextView `textView.string = text` 是 **纯 plain text**, wikilink **没高亮也没可点击** — 用户看不到链接.

**P2-3 目标**: Source 模式也高亮 + 可点 + 菜单栏 Insert Wikilink 快速插入.

## 2. 设计

### 2.1 WikiLinkExtractor (DreamEngine, pure function)

扫 markdown 找 `[[target]]` 跟 `[[target|alias]]`, 返 `WikiLinkSegment { target, label, range, linkURL }`.

**算法**: 单 pass, O(n):
- 找 `[[` 起始
- 找 `]]` 收尾 (不跨行)
- 解析 inner: 第一个 `|` 切 target / alias
- 编 URL: `dreamvault://wikilink/<encoded target>`
- 跟现有 MarkdownRenderer / WikilinkResolver 格式完全一致

**已知 edge case**:
- 跨行 `[[a\nb]]` 忽略 (单行 wikilink)
- `[[]]` 忽略 (空)
- 单 `[a]` 不当 link (要 `[[`)
- 中文 / 空格 / `.md` 路径都支持 (URL encoding 处理)

### 2.2 NSTextViewRepresentable 改造

`textView.string = text` → `textView.textStorage?.setAttributedString(WikiLinkExtractor.attributedString(from:))`. 保留 base font / color, 加 wikilink 段 .link + 蓝色 + 下划线.

**关键**: 已有 `clickedOnLink` callback (`Coordinator.textView(_:clickedOnLink:at:)`) 自动处理 dreamvault:// → 走 onWikilink → AppModel.openMemory, **不用新写跳转逻辑**.

### 2.3 Insert Wikilink sheet

SwiftUI sheet, 380x280, 两个 TextField (target / alias), Preview 段实时显示插入字符串, 提交后 append 到 `editorState.buffer` (末尾追加, 简化版 — 不拿 NSTextView 真光标, 避免 bridge 复杂度). 用户可手动移动到想要位置.

**未来 TODO**: 拿 NSTextView.selectedRange 真正插光标 (P10+).

### 2.4 菜单栏入口

MenuBarController 加 "Insert Wikilink…" 菜单项 (Cmd-Shift-K), 跟 Search / Graph 同一套 4 步骤模式 (NSMenuItem + @objc + AppActions + Notification).

## 4. 踩坑记录 (2 条)

1. **`[[swiftui]]` 长度算错**: 第一次写测试 `range.length = 10` (2+7+2=11, 我手算成 10). 改 11. 经验: **NSRange.length 一律用 `text.utf16.count` 或 `String.count` 算, 别心算**.
2. **NSTextView 拿光标难**: 想把 wikilink 插到 NSTextView.selectedRange, 但 MainView.onAppear 拿的 textView 跟 NSTextViewRepresentable 内部 textView 不是同一个引用 (NSTextViewRepresentable 用 Coordinator 持有). 桥接复杂. **简化**: 走 EditorState.buffer append 末尾, 用户移动. P10+ 优化. 经验: **不要为了 perfect 把 bridge 复杂化, ship 80% 价值用 20% 工作量**.
