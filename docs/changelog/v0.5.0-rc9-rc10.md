# v0.5.0-rc9 → v0.5.0-rc10: P2-1 菜单栏常驻 (完整版)

> **核心**: 菜单栏常驻 (NSStatusItem) + 6 菜单项 + Recent Memory 子菜单 + 3 状态 icon + UNUserNotification 夜间跑完通知. 完整版含通知.

## 1. 背景与动机

v0.4 只有主 window + dock icon, 跑 dream 要打开 window. v0.5 加完 Reinforcer / Cost pre-screener / Fabrication gate 后, dream 跑得越来越自动化, 用户不需要常开 window, 但**需要知道跑完了什么 / 失败在哪**. 

**P2-1 完整版目标**: 把 DreamVault 升级为"常驻菜单栏 app", 用户不打开 window 也能:
- 看 status (idle / running / hasNew)
- 一键 Run Dream Now (Shift-Cmd-D)
- 浏览最近 8 条 durable 记忆 (Recent Memory 子菜单)
- 一键 Search (Shift-Cmd-F)
- 跑完弹本地通知 (N accepted, 含 top excerpt 前 80 字)
- 点通知直接 Finder 打开 vault

## 2. 设计

### 2.1 MenuBarController (新文件)

AppKit NSStatusItem + NSMenu 模式. 不走 SwiftUI MenuBarExtra (后者 macOS 13+ 才能用, 而且难 customization).

```
status item: moon.stars (idle) / moon.stars.fill (running) / 红色 badge N (hasNew)
```

### 2.2 6 菜单项

```
Open Vault           (Shift-Cmd-O)
Run Dream Now        (Shift-Cmd-D, running 时 disabled)
─────
Recent Memory ▸      (子菜单: last 8 durable, 截断 60 字, tooltip 完整 text)
Search…              (Shift-Cmd-F, 弹 SearchSheet)
─────
Settings…            (Cmd-,)
Quit DreamVault      (Cmd-Q)
```

子菜单用 `NSMenu.addItem(_:)` 配 `submenu:`, 标准 NSMenu 模式.

### 2.3 3 状态 icon

- `.idle`: `moon.stars` (Template image, 自动 follow 浅深色)
- `.running`: `moon.stars.fill` (实心, 表示在跑)
- `.hasNew(N)`: `moon.stars.fill` + 红色 NSTextField subview (红色 12pt badge)

每次 `setState` 切 image + 重建 subview. Badge 跟 N 字符宽度自适应.

### 2.4 UNUserNotification 通知

- 启动时 `UNUserNotificationCenter.requestAuthorization(options: [.alert, .sound, .badge])`
- dream 跑完 (AppModel.runDream catch 后) 调 `MenuBarController.shared.notifyDreamFinished(accepted:archived:topExcerpt:)`
- 通知 title = "DreamVault: N accepted, M archived", body = top excerpt 前 80 字 (没有就 "Tap to open vault")
- 点通知: `NSWorkspace.activateFileViewerSelecting([vaultRoot])` Finder 高亮 vault 根
- 前台通知也弹 (willPresent 返回 [.banner, .sound])

### 2.5 AppModel.openMemory

加方法 `AppModel.openMemory(_ mem: Memory)` — 把 selectedFile 设到 mem 的第一个 source. 菜单 Recent Memory tap → model.openMemory → MainView editor 跳过去.

## 4. 踩坑记录 (3 条)

1. **`IconState` 没 Equatable** 导致 `!=` 编译错. 改 `public enum IconState: Equatable` 一行解决. 经验: **Swift enum 跨函数比较必加 Equatable, 跟 Hashable 类似**.
2. **AppModel 跟 MenuBarController 启动顺序**: MenuBarController.start 需要 model, 但 AppDelegate 不知道 model (它在 SwiftUI @StateObject). 解决: 在 WindowGroup 的 MainView.onAppear 注入 (idempotent — start 内部 if statusItem != nil return). **不**在 AppDelegate.applicationDidFinishLaunching 调 (拿不到 model).
3. **AppModel.openMemory 命名冲突**: 我先在 AppActions 加 `openMemory` 静态方法, 后来又加 `AppModel.openMemory` 实例方法. 删 AppActions 那个 (实例方法更合理 — 跟 m.openVault 一致, m 开头的). 经验: **有 model 引力的操作放实例方法, 跟其他 model.action 保持一致**.
