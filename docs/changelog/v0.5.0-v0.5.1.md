# v0.5.0 → v0.5.1: P2-5 视觉系统统一 (DesignTokens)

> **核心**: 抽 DesignTokens.swift (5 类 token: Spacing/Radius/AppFont/AppColor/AppShadow + View modifier), 回填 P2-1/2/3/4 新件 + 基础 view (ConflictResolutionView + SettingsView).

## 1. 背景与动机

v0.4 → v0.5 ship 了 11 个新件, 每件都自己定义 padding (8, 12, 16), cornerRadius (4, 6, 8), color (`.secondary`, `.yellow.opacity(0.15)`). **没有统一** — 改一个 padding 数字得搜全 codebase.

**P2-5 DesignTokens**:
- 抽 5 类 token 到 `Sources/dream/DesignTokens.swift` (DreamEngine 不能放 — Color NSColor 是 AppKit)
- 5 个新件 (SerendipityBanner / InsertWikilinkView / GraphView / ConflictResolutionSheet / 等等) + 2 个基础 view (ConflictResolutionView / SettingsView) 改用 token
- 加 `.card()` / `.bannerStyle()` modifier, 一行套样式

## 2. 设计

### 2.1 5 类 token

```swift
public enum Spacing {  // 8 倍数 grid
    static let xxs = 2, xs = 4, sm = 8, md = 12, lg = 16, xl = 24, xxl = 32
}
public enum Radius {
    static let sm = 4, md = 6, lg = 8, xl = 12, pill = 999
}
public enum AppFont {
    static let body, caption, caption2, title3, title2, mono, monoSmall
}
public enum AppColor {
    // 背景: background / surface / elevated
    // 文字: textPrimary / textSecondary / textTertiary
    // 边框: divider / outline
    // 状态: accent / success / warning / danger / info
    // banner 背景: warningBackground / infoBackground / dangerBackground
}
public enum AppShadow { sm, md, lg }
```

### 2.2 语义命名 (不绑 hex)

Color 走 `Color(NSColor.windowBackgroundColor)` / `.labelColor` 等, **不绑具体 hex**. 改 macOS 系统主题 / light/dark 模式自动跟随.

GraphView 节点配色 (kind → Color) 保留 `.blue/.orange/.purple` magic — 这是 kind semantic (entity/concept/synthesis), 不是 design token.

### 2.3 View modifier

```swift
View.card(padding:radius:)  // 标准卡片 (surface + radius + shadow)
View.bannerStyle(.warning)  // banner (warning / info / danger 背景)
```

modifier 内部用 token, 调用方一行.

### 2.4 回填范围

- **P2-1/2/3/4 新件** (5 个): SerendipityBanner, InsertWikilinkView, GraphView 100% 回填 padding/cornerRadius/font/color
- **基础 view** (2 个): ConflictResolutionView (7 magic padding → 7 token), SettingsView (1 padding)
- **没回填的**: EditorPane (NSTextView 桥接, padding 不多), DiffViewerView, SearchSheet (下一波 P5+ 慢慢做)

## 4. 踩坑记录 (1 条)

1. **Sed 跟 Python 替换覆盖不到所有 case**: `padding(2)` 跟 `spacing: 2,` 跟 `spacing: 2)` 三种 syntax. sed 一刀切漏 spacing 里的 2 (因为没匹配后面字符). 修: Python 走 str.replace, 然后 sed 走 `s|spacing: 2)|spacing: Spacing.xxs)|g` 抓闭括号无逗号. **经验: bulk token 替换要分两轮 (Python 一轮 + sed 闭括号一轮), 别图省事一行 sed**.
