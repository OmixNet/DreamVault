# v0.5.0-rc8 → v0.5.0-rc9: P1-1 durable 100+ 推 3-Step CoT banner

> **核心**: Settings → Dream tab 顶部加 banner, vault 里有 ≥ 100 条 durable 记忆且 3-Step CoT 未开时, 推荐用户开 3 段. **不自动开**, 用户主动点 "Enable 3-Step CoT".

## 1. 背景与动机

3 步 CoT (analyze → generate → verify) 防幻觉 (尤其 P0-3 假 excerpt 闸门) 更好, 但慢 3 倍. 默认 OFF (P3 T6 用户决策). 问题是: 啥时候该开? 没指引.

**P1-1 经验阈值**: durable 100 条是分水岭.
- < 100 条: 矛盾检测走 LLM 仍能跑全, 3 段必要性低
- ≥ 100 条: 矛盾检测候选数上升, fabricated excerpt 风险增加, 3 段性价比反转

**设计**: 不自动开, 推 banner 让用户自决. 避免 surprise. banner 一次性, 用户忽略再开 Settings 仍看到 (P1-1 简化, 不持久化 dismiss).

## 2. 设计

### 2.1 banner UI

```
┌────────────────────────────────────────┐
│ 💡 Recommendation                      │
│   You have 250 durable memories        │
│   With 100+ memories, 3-Step CoT       │
│   reduces hallucination significantly  │
│   ...                                  │
│   [✓ Enable 3-Step CoT]  Maybe later   │
└────────────────────────────────────────┘
```

- 黄色背景 (yellow opacity 0.12)
- 黄色 lightbulb 图标
- 文案具体 (durable 数 + 3 段作用)
- "Enable 3-Step CoT" 按钮 = borderedProminent (蓝色突出)
- "Maybe later" 按钮 = borderless + 灰色, 不持久化

### 2.2 条件判断 helper

```swift
static let threeStepBannerThreshold = 100
static func shouldShowThreeStepBanner(durableCount: Int, useThreeStepCoT: Bool) -> Bool {
    durableCount >= threeStepBannerThreshold && !useThreeStepCoT
}
```

抽成 `static func` 让 test 覆盖.

### 2.3 vaultPath 注入

`SettingsView.init(vaultPath: String)` 接收 path, 打开时立即 `Persister.loadLedger` 算 durable count. 没 path (未初始化 vault) → 0 → banner 不显示.

`Entry.swift` Settings scene 传 `model.vaultRoot.path`.
