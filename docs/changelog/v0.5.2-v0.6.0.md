# v0.5.2 → v0.6.0: P3-1 durable 同质合并 (评审 §1.1 修复)

> **核心**: 字符 trigram Jaccard 同质合并. 新教训 vs 现有 durable, 命中阈值 (>= 0.6) 把新 source 追加进现有条目, 不新建. 修评审 §1.1 "durable 永远不可达" 结构性缺口.

## 1. 背景与动机

评审 §1.1 指出: 在生产管线下, `Gatherer.gather()` 每文件产 1 candidate (1 source), `MemoryDraft.sources = [draftSource]` (1 source), `classify()` 要求 distinct sources >= 2 才升 durable — **永远升不了 durable, MEMORY.md 永远是空, Persister 写不出 wiki 页**.

修复核心: dream cycle 第 2c 步加 "同质合并" — 新教训跟现有 durable 比相似度, 命中阈值则合并 (把新 source 追加进现有, 触发 Reinforcer).

## 2. 设计

### 2.1 TextSimilarity (新, pure function)

字符 trigram Jaccard, **不用 embedding** (P3-6 才会做):
- **trigram**: 3 字符 sliding window
- **归一化**: lowercase + collapse whitespace + 去标点 (保留 ASCII alnum + space + CJK U+4E00-U+9FFF)
- **Jaccard**: |A ∩ B| / |A ∪ B|, 0.0 ~ 1.0
- **阈值 0.6**: 经验值, 平衡漏检 / 误合

为什么 trigram + Jaccard 不用 embedding:
- 中文友好 (字符粒度, 不分词)
- O(n) 计算, 大文件秒返
- 0 依赖 (P3-6 再切 NLEmbedding)
- 阈值可调

### 2.2 DreamCycle.mergeSimilar (新, static func)

```swift
public static func mergeSimilar(
    newAccepted: [Memory],
    existing: [Memory],
    now: Date = Date(),
    threshold: Double = TextSimilarity.mergeThreshold
) -> (newAccepted: [Memory], updatedExisting: [Memory], mergeCount: Int)
```

行为:
1. **只跟 `status == .durable` 比** (candidate 之间合并留给 P10+ — 复杂度)
2. 新条跟现有每个 durable 比 Jaccard, 命中阈值合并
3. 合并: sources 累加去重, lastAccess = now, reinforceCount += 1, status 重 classify (>= 2 sources 自动升 durable)
4. 一条新教训只合并 1 次 (跟最相似的现有)

### 2.3 DreamCycle.runOnce 集成

矛盾检测 (§2b) 之后, "把新教训合并到 ledger" 之前, 加 P3-1 阶段 (§2c):

```
gather (candidates)
  → consolidate (2 步 / 3 步 CoT)
  → contradictions link (§2b)
  → **P3-1 同质合并** (§2c)  ← 新增
  → persist (ledger.json)
  → persist (wiki/ pages)
  → commit
```

## 4. 踩坑记录 (4 条)

1. **CharacterSet.unicodeScalars 不存在**: 第一版用 `CharacterSet.unicodeScalars(for: .ideographicDescription)` 找 CJK 范围, 编译失败. Swift `CharacterSet` API 没这方法. 改 hardcode unicode range `0x4E00...0x9FFF`. 经验: **CJK 范围直接 hardcode, 别用 CharacterSet 高层 API**.
2. **trigram threshold 调参反复**: 第一版 0.5 阈值, 测试发现 "SwiftUI 用于 macOS 桌面 UI" vs "AppKit 用于 macOS 桌面 UI" sim = 0.5, 边界触发合并 (错). 改 0.6, "完全不同主题短文本" sim < 0.3, "同教训略变" sim > 0.8. 经验: **trigram Jaccard 短文本偏激进, 阈值 0.6+ 才是合理点**.
3. **P3-1 限制只跟 durable 比**: 第一版 `durIdx.isEmpty ? candidateIdx : durIdx`, 候选也合并. Test fail: 候选之间合并让 testNoDurableToMerge 行为变, 跟设计意图不符. 改: **只跟 durable 比** (candidate 之间合并留给 P10+ 扩展). 经验: **设计意图写进 test 名字, 比 "通用合并" 简单但语义对**.
4. **build cache 没清**: sed 改 `searchIdx` → `durIdx` 时, 只改 1 处, build 看到 .build cache 跳过 Swift 重新解析, 报 "cannot find 'searchIdx'". 修: `mavis-trash .build`. 经验: **rename 变量后必 trash .build, cache 不会自动更新 source 文件列表**.
