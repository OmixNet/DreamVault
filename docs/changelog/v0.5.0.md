## 4. 重大技术决策

| 决策 | 选择 | 替代 | 理由 |
|------|------|------|------|
| 图谱渲染 | SwiftUI Canvas | SpriteKit / WebKit+d3 | Metal 加速 60fps, 无 bundle size 负担 |
| 矛盾检测预筛 | Token + 图谱 0 成本 | 纯 LLM 调用 | 99% 节省, P0-1 验收数据 |
| 3-Step CoT 默认 | OFF | ON | 慢 3 倍, 默认 OFF, banner 推 (P1-1) |
| 菜单栏 | NSStatusItem AppKit | SwiftUI MenuBarExtra | 后者难 customize, AppKit 4-步骤标准化 |
| Wikilink 高亮 | textStorage attributed | 渲染层 | Source 模式也支持, 走已有 clickedOnLink |
| Serendipity | 同日 stable hash | 每次 random | 同一启动多次看到同一条, 跨日换 |
