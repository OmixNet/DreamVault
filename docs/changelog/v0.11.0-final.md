## P1.2: Markdown 语法高亮 (4 类) (缺陷报告 §3.3 P1.2)

**根因** (`Sources/dream/NSTextViewRepresentable.swift` 老实现):
NSTextView 编辑器只显示 wikilink (P2-3 修过), 不显示 markdown 标记. 用户
看 Source 模式时, `**粗体**` `\`code\`` `# 标题` 都跟正文同色, 不区分.

**修法**: `MarkdownHighlighter` 新文件, 4 类高亮:
- **标题** (# ## ###): 蓝色 + 加粗
- **粗体** (**...**): 粗体
- **行内代码** (\`...\`): 等宽 + 灰底 (跟正文区分)
- **链接** ([text](url)): 蓝色 + 下划线

`NSTextView.applyAttributedText(to:from:)` 集成 — 先 WikiLinkExtractor
标 wikilink (.link attribute + 蓝色), 再 MarkdownHighlighter 标 markdown
4 类 (跳过 wikilink 范围避免双重着色).

**新文件**: `Sources/dream/MarkdownHighlighter.swift` (~148 行)
**改动**: `Sources/dream/NSTextViewRepresentable.swift` 集成高亮
**单测**: `Tests/DreamTests/MarkdownHighlighterTests.swift` (12 case)
